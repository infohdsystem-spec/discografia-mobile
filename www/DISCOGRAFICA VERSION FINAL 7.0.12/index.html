        Bienvenido a Discografía

        Versión 7.0.12 · Colección profesional de CDs

        Discografía v7.0.12 es una aplicación web autocontenida para catalogar, organizar, enriquecer y analizar tu colección.

        🆕
        Novedad v7.0.12: auditoría completa de código con correcciones de consistencia (regex ISRC, manejo de errores en backup automático, modales full-screen en móvil chico, limpieza de código duplicado).
        📱

        Modo móvil

        Desde v7.0.11 la app se adapta automáticamente a cualquier tamaño de pantalla.

        📐 Breakpoints

        AnchoComportamiento
        ≥1024pxLayout desktop de 2 columnas
        768–1024pxTablet: panel artistas más angosto
        560–768px1 columna, panel artistas abajo, modales compactos
        380–560pxMobile portrait: header ultra compacto, modales full-screen
        ≤380pxMobile chico: 2 tarjetas por fila, botones full width

        👆 Táctil

        • Botones con altura mínima 42px (norma Apple/Google).
        • Acciones de fila siempre visibles (no dependen de hover).
        • Streaming con targets de 44px.

        🍎 iOS

        • Respeta env(safe-area-inset-*) para iPhone con notch.
        • Usa 100dvh para adaptarse a la barra de URL dinámica.
        💡
        Podés instalar la app en tu celular con "Agregar a pantalla de inicio" desde Chrome/Safari.
        📂

        Subcategorías

        Desde v7.0.10 podés organizar cada categoría en subcategorías.

        🎯 Cómo funciona

        1. Elegí una categoría (no "Todas").
        2. Debajo de las pestañas aparece la barra de subcategorías con el botón ➕ Crear primera subcategoría.
        3. Poné nombre e icono → Guardar.
        4. En el modal de un CD, elegí 📂 Subcategoría.
        5. Botón ⋯ de la subcategoría → renombrar / cambiar icono / mover / eliminar.
        ✅
        Eliminar una subcategoría NO borra CDs.
        🎧

        Streaming inteligente

        Desde la vista de un CD aparece la sección 🎧 Escuchar en.

        1. Si el CD ya tiene link guardado, abre directo.
        2. Si no, busca en iTunes Search API.
        3. Usa Odesli/song.link para mapear a otras plataformas.
        4. Aparece un modal de confirmación.
        ✅
        100% legal: NO descarga audio.
        ⚖️

        La primera vez aparece un modal con el aviso legal.
